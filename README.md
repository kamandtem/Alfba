# تخته جادویی الفبا و ریاضی

بازی آموزشی فارسی پایه اول با React، TypeScript و Vite. تخته واژه‌سازی از حروف خالص، اتصال پویای شکل حروف، چسبیدن اعراب، تشخیص واژه، تلفظ و بازخورد تشویقی پشتیبانی می‌کند و در حالت عمودی و افقی واکنش‌گراست.

## اجرای محلی

```bash
npm install
npm run dev
```

## ساخت وب

```bash
npm run build
npm run preview
```

## ساخت Android

نیازمند Android Studio، JDK 21 و Android SDK است:

```bash
npm install
npm run android:add   # فقط بار اول
npm run android:sync
npm run android:open
```

در Android Studio گزینه Build APK را اجرا کنید. برای GitHub کافی است پروژه را روی شاخه `main` پوش کنید یا workflow با نام **Build Android APK** را دستی اجرا کنید؛ فایل APK در Artifacts همان اجرا قرار می‌گیرد.

## معماری آموزشی (نسخه جزیره الفبا)

- **تقویم محتوایی** (`src/data/curriculum.ts`): ۴۰ درس به ترتیب دقیق کتاب فارسی اول (نشانه‌ها ۱: ۳۱ درس، نشانه‌ها ۲: ۹ درس) با هفتهٔ آموزشی هر درس از اول مهر. درس پیشنهادی امروز خودکار حساب می‌شود و «درس من» از نقشه قابل تغییر است.
- **بانک واژه** (`src/data/wordBank.ts`): حدود ۴۵۰ واژه و ۸۰ جملهٔ اعراب‌دار؛ درسِ هر واژه خودکار از روی نشانه‌هایش محاسبه می‌شود تا هیچ تمرینی از نشانهٔ نخوانده استفاده نکند.
- **قوانین اتصال** (`src/utils/pieces.ts`): شکل‌های آموزشی (غیرآخر/آخر، اول/وسط/آخر چسبان/آخر تنها)، جلوگیری از ادامه بعد از شکل آخر (تنها استثنا: «می‌»)، شکل‌های فقط-اول (آ، اَ، اِ، اُ، او، ایـ)، اعراب و تشدید.
- **دهکده اول**: دست‌کشیدن روی شکل خط‌چین + «انجام دادم» با سنجش پوشش، پیدا کردن حرف در میان حروف خاکستری، «چی مثل چی»، فلش‌کارت.
- **دهکده دوم** (`WordVillage`): تختهٔ دوبخشی (جای حروف + تختهٔ مغناطیسی با خط چسبندگی)، جعبهٔ حروف به ترتیب کتاب، سه حالت: کلمه‌های درس / پیشنهاد کلمه / نوشتن آزاد با دکمهٔ پایان.
- **دهکده سوم**: جمله‌سازی فقط با جمله‌های متناسب با درس انتخاب‌شده.
- همهٔ حروف با فونت نوشتاری کتاب (`public/fonts/wm_Tahriri.ttf`) و بدون کادر نمایش داده می‌شوند.
